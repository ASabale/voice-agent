## 2. How the Live Loop Works

1. **Wake (`IDLE → DICTATING`)**:
   - Dual detector on a 16 kHz mono mic stream:
     - **Path 1**: `openWakeWord` (`hey_jarvis` ONNX, threshold `0.35` with 3x gain normalization when quiet; `0.50` without boost while VoiceBox is speaking).
     - **Path 2**: Silero VAD + `faster-whisper tiny.en` (CPU int8, `~100 ms`) on short `0.4s–3.2s` utterances in `IDLE` so bare `"Jarvis"`, accented `"Hey Jarvis"`, or standalone `"send prompt"` / `"scratch that"` never miss.
   - On wake: calls `POST http://127.0.0.1:17494/barge-in` (`abortAgent: true`) + `killall afplay`, plays `marimba_start.wav`, runs `handy --cancel` then `handy --toggle-transcription`, and unmutes macOS audio at `+150 ms` and `+800 ms`.
2. **Chunked Dictation (`DICTATING`)**:
   - **Normal Speech (5.0s Silence Pause)**: Toggles Handy off to transcribe, waits `260 ms` for Handy's `Cmd+V` paste to finish, deduplicates against the OMP editor via `ctx.ui.getEditorText()` / `ctx.ui.setEditorText()`, pushes the pre-chunk state onto `draftHistory`, plays `Tink.aiff`, and immediately re-toggles Handy on for the next thought.
   - **Fast Command Flush (1.5s Silence Pause)**: Rolling 3.0s tail buffer checked by `faster-whisper tiny.en` after `1.5s` of silence so spoken commands execute without waiting 5 seconds:
     - **Submit (`Enter`)**: `"send prompt"`, `"send that"`, `"send it"`, `"submit prompt"`, `"send message"`, `"press enter"`, `"ship it"`, `"hey jarvis send"`, `"jarvis send"` → strips the command phrase, appends any leading words, clears the OMP editor, and calls `pi.sendUserMessage(finalDraft)`. Plays `marimba_stop.wav` and returns to `IDLE`.
     - **Scratch / Undo**: `"scratch that"`, `"scratch last"`, `"undo that"`, `"delete that"`, `"erase that"`, `"remove last"` → pops the last pasted chunk from `draftHistory` (or discards the current chunk if spoken mid-sentence), updates the OMP editor on screen, plays `Basso.aiff`, and **stays in `DICTATING`**.
     - **Clear Entire Draft**: `"clear draft"`, `"clear all"`, `"clear text"`, `"clear box"`, `"scratch all"`, `"start over"` → wipes the OMP editor (`""`) and `draftHistory`, plays `Basso.aiff`, and **stays in `DICTATING`**.
     - **Pause / Sleep**: `"pause listening"`, `"stop listening"`, `"hey jarvis stop"`, `"jarvis stop"`, `"stop dictation"`, `"stop"` → keeps the draft in the OMP editor without pressing Enter, plays `Pop.aiff`, and returns to `IDLE`.
     - **Cancel Chunk**: `"cancel that"`, `"discard chunk"`, `"cancel dictation"` → discards the current chunk and returns to `IDLE`.
   - **15s Idle Timeout**: If 15s passes in `DICTATING` with zero speech, cancels Handy (`handy --cancel`) and returns to `IDLE`.
3. **Headphone / AirPods Hotplug**:
   - Polls CoreAudio `kAudioHardwarePropertyDefaultInputDevice` (`0x64496E20`) every `2.0s` via `ctypes`. When headphones/AirPods connect or disconnect, re-initializes PortAudio (`sd._terminate()` / `sd._initialize()`) and rebinds the input stream automatically.
4. **Resilience Against `Escape` / Manual `fn` Interference & Port Takeover**:
   - **Local Whisper Recovery (`transcribe_local_fallback`)**: Buffers speech PCM in RAM during `DICTATING`. If pressing `Escape` in the terminal cancels Handy's active recording (or if Handy is closed/updating), `omp-voice-controller` transcribes the buffered audio directly with local `faster-whisper tiny.en` so dictated speech is never lost.
   - **Manual `fn` Sync**: Detects if the user manually pressed `fn` mid-session (producing a new `history.db` row early) and dispatches it immediately without double-toggling Handy out of sync.
   - **Zero-Delay Start**: Plays the Wake chime (`marimba_start.wav`, `wait=False`) concurrently with starting Handy so words spoken immediately after `"Hey Jarvis"` are captured.
   - **Automatic `:17494` Takeover (`POST /takeover`)**: When a new OMP session starts while an older OMP session still holds `127.0.0.1:17494`, the new session sends `POST /takeover` to release the port from the old session and binds it automatically.
5. **On-Demand Humanized Voice Output (`voice-brief` + `/voice human`)**:
   - **Off by default** across all sessions (`humanizeMode = false`).
   - **On demand**: Invoke the `voice-brief` skill (`~/.omp/agent/managed-skills/voice-brief/SKILL.md`) or run `/voice human` (`on`/`off`) in a session. When active, OMP prepends a `**Voice:** <1–3 sentence plain-English takeaway>` above technical tables/paths/code, and `forSpeech()` speaks **only** the `**Voice:**` summary while keeping the full technical output on screen. Even when off, `forSpeech()` strips markdown tables, code blocks, long file paths, ISO/log timestamps, UUIDs, and `(pid ...)` metadata from spoken audio.
6. **Upgrade Robustness Across OMP, Handy, and VoiceBox**:
   - Zero modifications inside `/Applications/Handy.app`, `/Applications/Voicebox.app`, or `/opt/homebrew/Cellar/omp`.
   - OMP extensions live in `~/.omp/agent/extensions/voicebox-speech.ts` (public `ExtensionAPI`); controller lives in `~/.local/bin/omp-voice-controller` + `~/.local/share/omp-voice/venv`.
